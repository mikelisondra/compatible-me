# Compatible Me.io

**Compatible Me.io** is a real-time multiplayer social synchronization game designed to test how well friends, couples, and groups actually know each other.

## 🎮 How It Works
One player acts as the **VIP (Host)** and answers a question about themselves. Everyone else attempts to guess the VIP's answer. The closer the guess, the higher the compatibility score.

## ✨ Features
* **❤️ 1v1 Duel:** Intimate mode for couples.
* **🎉 Party Mode:** Competitive mode for groups.
* **📊 Ranking & Trivia:** Drag-and-drop or multiple choice.
* **Custom Topics:** Input your own questions.
* **Audio FX:** Professional sound system.
* **Serverless:** Built on Firebase Realtime Database.
